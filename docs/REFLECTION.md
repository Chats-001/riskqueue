# Personal reflection — author draft prompts

Write 300–500 words in your own voice before publishing.

1. What did I initially misunderstand about fraud detection?
2. What was harder: the model or the decision system around it?
3. Which design decision had the largest effect?
4. What technical skill did I improve most?
5. What would I change with real company data?
6. How did this project change how I think about applied AI?
